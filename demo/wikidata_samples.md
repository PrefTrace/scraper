# Примеры ORM-данных Wikidata

Файл `wikidata.sqlite3` содержит нормализованные записи. Ниже — несколько
значений, прочитанных из базы после прогона демо для Portal 2 (`AppID 620`,
`Q279446`). Это не JSON-ответ скрапера, а удобная человекочитаемая выборка из
ORM-таблиц.

| Смысл | Property | Значение |
|---|---|---|
| Серия | `P179` | `Q7231475` — Portal |
| Предыдущая игра | `P155` | `Q274897` — Portal |
| Разработчик | `P178` | `Q193559` — Valve Corporation |
| Издатель | `P123` | `Q193559` — Valve Corporation |
| Минимум игроков | `P1872` | `+1` |
| Максимум игроков | `P1873` | `+2` |
| Движок | `P408` | `Q643572` — Source |
| Актёр озвучки | `P725` | `Q4738855` — Alésia Glidewell |

Для серии порядковый номер хранится в `wikidata_qualifiers` как qualifier
`P1545` у факта `P179`. Роли персонажей, даты продаж и штат организаций
хранятся тем же способом — как факты с qualifiers, а не как вложенные JSON
объекты.

После этого прогона в базе было 1 447 сущностей, 45 809 фактов и 52 134
qualifiers. В `wikidata_benchmark.json` отдельно записаны время, количество
HTTP-запросов и состояние обновления каждого AppID.
